# Microservices in Nodejs
This project is basic demo of Microservices in Nodejs, Along with API gatway. In this project we have three Microservices, as slisted below
1. [User Service](https://github.com/lokeshwaran-kapden/Microservices/tree/main/UserService)
2. [Product Service](https://github.com/lokeshwaran-kapden/Microservices/tree/main/ProductService)
3. [Order Service](https://github.com/lokeshwaran-kapden/Microservices/tree/main/OrderService)

## User Service
This service will implement the User related APIs.

## Product Service
This service will implement the Product related APIs.

## Order Service
This service will implement the Order related APIs.

## API gateway
An [API Gateway](https://github.com/lokeshwaran-kapden/Microservices/tree/main/APIGateway) where you will add Rate Limit and other Authentications.
